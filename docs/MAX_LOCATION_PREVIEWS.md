# Изображения всех локаций MAX

Владелец одобрил стиль первых четырёх сцен. Созданы оставшиеся 93 иллюстрации:
теперь у всех 97 локаций есть новая карточка MAX. Исходные изображения Telegram
не заменены. Полный JPEG-набор занимает около 25,5 МБ, сторона до 1280 пикселей.

| Карточка | ID | Как попасть со стартовой площади |
|---|---|---|
| Площадь Туманного Брода | village | `/start` или «Осмотр» на площади |
| Торговый ряд | market | Север |
| Святилище Рассвета | temple | Юг |
| Старый подвал | cellar | Вниз |

Из торгового ряда вернуться на площадь можно на юг, из святилища — на север,
из подвала — вверх. В подвале есть крысы; это игровая локация, не отдельный просмотрщик.

Иллюстрации показываются вместе с текущим описанием и кнопками комнаты после создания
героя, при `/start`, осмотре, перемещении, возрождении и возврате из боя. Если файл отсутствует или отключён флаг
`roompics`, карточка тоже остаётся текстовой, без сломанного изображения.

Пути: `images/room_previews/<room_id>.jpg`. Исходники PNG локальные,
не публикуются и не попадают в Docker. Все иллюстрации созданы встроенным imagegen
отдельными вызовами, по описаниям из `data/world.yaml` (загружаемый `content.WORLD`).
Полные промпты и исходные описания: [LOCATION_PREVIEW_PROMPTS.json](LOCATION_PREVIEW_PROMPTS.json)
и [LOCATION_ART_REMAINING_PROMPTS.json](LOCATION_ART_REMAINING_PROMPTS.json).

Компрессия только этой папки:

```bash
python scripts/optimize_images.py --only room_previews --keep-png
```

Для применения нужен обычный Redeploy в Coolify. Новые переменные, изменение БД или
повторная регистрация webhook **не нужны**. Игровые данные и баланс не изменены.

Карта `/map` теперь имеет отдельную графическую схему и навигацию к выбранному
заданию/поручению. См. [MAX_MAP_DESIGN.md](MAX_MAP_DESIGN.md). Карта рисуется кодом,
а не ИИ: переходы берутся из настоящего графа мира.

Проверки: `test_max_locations.py`, общий прогон тестов и PostgreSQL-проверка доставки
медиа через существующую outbox. Реальное отображение в приложении MAX оценивается
владельцем после редеплоя.
