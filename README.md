# 🗡 СЕМЬ КОРОН v3 — фэнтези-MUD-ядро для Telegram

Полноценное MUD-ядро: **6 классов и 5 рас со своими характеристиками и умениями**, **реал-тайм бой** (мобы атакуют сами по таймеру, как в классических MUD), **кооператив** (несколько игроков бьют одного моба и делят опыт по вкладу, жрец лечит союзников), **экономика** (магазин, продажа добычи, крафт, аукцион, гильдийский банк), **квесты**, **гильдии, фракции и территории**, **сезоны и реморт-престиж**, **ИИ-слой** (живые диалоги NPC под бюджетом), **PostgreSQL** для хранения. Мир — **97 рукотворных локаций** плюс **194 процедурные** в шести диких регионах (флаг `WILD_ZONES`, 291 комната всего) и **78 видов существ**. Дикие регионы уровневые: каждый подписан в шапке комнаты («ур.17–19») и подвешивается к рукотворной локации своей сложности. Весь контент вынесен в **YAML** — мир расширяется без правки кода.

## Установка и запуск

### 1. Зависимости
Требуется **Python 3.12+**.
```bash
pip install -r requirements.txt -c constraints.txt
```
`constraints.txt` фиксирует проверенные точные версии зависимостей (см. файл).
Диапазоны версий по-прежнему заданы в `requirements.txt` — `constraints.txt`
их не расширяет, только сужает до конкретных релизов.

### 2. PostgreSQL на VPS
```bash
sudo apt install postgresql
sudo -u postgres psql -c "CREATE DATABASE mud;"
sudo -u postgres psql -c "CREATE USER muduser WITH PASSWORD 'ВСТАВЬ_СВОЙ_ПАРОЛЬ';"
sudo -u postgres psql -c "GRANT ALL ON DATABASE mud TO muduser;"
```
Таблицы создаются автоматически при первом запуске.

### 3. Переменные окружения и запуск
```bash
export BOT_TOKEN="токен_от_BotFather"
export DATABASE_URL="postgresql://muduser:ВСТАВЬ_СВОЙ_ПАРОЛЬ@localhost/mud"
cd mud2
python -m bot.main
```

> Если `DATABASE_URL` недоступен, игра **всё равно запустится** без сохранения (удобно для локальных тестов) — в консоли будет предупреждение.

## Геймплей

1. `/start` → выбор **расы** → выбор **класса** → ввод имени.
2. Дальше всё **кнопками**: атака, умения, перемещение, сумка, магазин, квесты.
3. В бою мобы бьют **сами** по таймеру — лечитесь и бейте в ответ.
4. Умри — очнёшься в **Святилище** (запад от деревни), там же полное восстановление.
5. Три пути к руинам: **лес** (север), **рудники** (восток, там кузнец-магазин/крафт), **болото** (юг). Все сходятся у **Врат**, за ними — **Падший Король** (480 HP, зовите друзей в кооп).

Текстовые команды-помощники: `сказать <текст>` (чат комнаты), `кто` (онлайн), `купить <предмет>`, направления словами.

## Классы

- **⚔️ Воин** — много HP, урон от Силы, −20% получаемого урона. Умения: Мощный удар, Стена щитов, Рассекающий удар.
- **🔮 Маг** — большой бурст от Интеллекта, мало HP, зависит от маны. Огненный шар, Ледяная броня, Чародейский залп.
- **🗡 Разбойник** — урон от Ловкости, +15% крит, 25% двойной удар. Удар в спину, Уклонение, Отравленный клинок.
- **✨ Жрец** — лечит себя и **союзников в комнате** (ключевой для кооп), урон от Духа. Исцеление, Кара, Благословение.
- **🛡 Паладин** — гибрид: броня + урон от Силы + самолечение и AoE-лечение. Святой удар, Возложение рук, Освящение.
- **💀 Некромант** — урон от Интеллекта + **вампиризм** (возврат 25% урона в HP), хрупкий. Высасывание жизни, Костяная броня, Проклятие гнили.

**Расы** (реально влияют на билд): 🧑 Человек (+опыт), 🧌 Орк (+HP/Сила, без мага), 🧝 Эльф (крит/уворот, хрупкий), 🧔 Гном (прочность/золото), 👺 Гоблин (уворот/удача, только маг/разбойник/некромант).

## Экономика: магазин, продажа, крафт

У кузнеца (рудники) три вкладки:

- **🛒 Покупка** — зелья, оружие, броня, аксессуары.
- **💰 Продажа добычи** — скупка материалов и ненужного снаряжения за ~60% цены (надетое не продаётся). Даёт смысл всему луту.
- **🔨 Ковка** — крафт снаряжения из материалов + золото по рецептам из `recipes.yaml` (кольчуга, стальной меч, латы, кристальный амулет).

## Прогрессия и реморт

- **Уровни 1–25** — кап сведён к объёму рукотворного контента (полное прохождение ≈2,5–3 ч). Классовые умения изучаются в этом диапазоне, последние капстоуны — на 23–25.
- **Таланты** — очко раз в 2 уровня → **12 очков** за прохождение (жёсткий потолок: реморт сбрасывает уровень, очки не копятся кругами). Сумма рангов в дереве класса — 15, то есть вложить всё нельзя: ветку приходится выбирать.
- **Реморт-престиж — основная петля повторной игры.** На капе доступно перерождение: круг даёт навсегда **+5% к силе и здоровью** (потолок **+50%** на 10-м круге). Сбрасываются уровень и выученные умения (учатся заново по уровням — иначе круг превращается в каток); снаряжение, монеты и таланты сохраняются. Надетые вещи с требованием уровня выше текущего остаются у героя, но не дают бонусов, зачарования и рун, пока он не дорастёт до нужного уровня. Старые сюжетные задания и решения остаются памятью героя, а в каждом новом круге открывается отдельная цепочка более сложных испытаний. ИИ-NPC учитывает выполненные задания, если ИИ включён; сами цели и награды заданы игровым кодом и доступны без ИИ.
- **Эндгейм для перерождённых** — **46 реморт-предметов** (level_req 24–25) требуют 1–2 перерождения (⭐), не выпадают и не надеваются без реморта; финальный босс Предвечной Бездны (ур.30, выше капа) рассчитан на слаженную группу или перерождённых.

## Тесты

Движок тестируется без Telegram и без БД:
```bash
python run_tests.py            # 40 автономных файлов; PostgreSQL-тест без TEST_DATABASE_URL пропускается
python run_tests.py engine     # только тесты, чьё имя содержит «engine»
python run_tests.py --quick    # пропустить помеченные медленными
```
Тесты лежат в `tests/` и запускаются раннером, а не напрямую: корень проекта
попадает в `sys.path` через `PYTHONPATH`, который выставляет `run_tests.py`.

Для реальной проверки миграции и сохранения умений задайте `TEST_DATABASE_URL`
на **отдельную тестовую PostgreSQL**, затем выполните
`python run_tests.py postgres_skills`. Тест не читает `.env` и не использует
рабочую `DATABASE_URL`; создаёт уникальную схему и удаляет только её после
проверки. В CI для этого есть отдельная задача с PostgreSQL 16.

План исправлений и подключения MAX: [docs/MAX_MIGRATION_PLAN.md](docs/MAX_MIGRATION_PLAN.md).
Отчёт второго этапа: [docs/STAGE2_SERVER_COMBAT.md](docs/STAGE2_SERVER_COMBAT.md).

В живом боте атаки, умения, расходники и побег делят темп: одно действие в
секунду на героя, независимо от кнопки/текстовой команды/карточки предмета.
Откаты и временные эффекты героя идут по серверному времени. Активность —
входящий ввод за последние 5 минут, а не факт загрузки из БД или отправки ответа.
Фоновые push по умолчанию выключены: игрок включает их в настройках уведомлений.
Атмосферные строки получают только активные живые герои, без push-звука.

Сравнение серверного темпа без пополнения зелий и лечения между боями:

```bash
python -m sims.sim_server_combat --runs 10
```

Это локальный замер фиксированных сценариев, не подтверждение баланса всей игры.

## Флаги мира

Из коробки (`python -m bot.main`) включены восемь флагов «живого мира»: `NPC_AI` (NPC бродят/отдыхают вне боя), `LAZY_SIM` (докрутка мира за время оффлайна игрока), `WILD_ZONES` (дикие зоны вокруг основного мира), `WORLD_EVENTS` (мировые события по таймеру), `SEASONS` (сезонный трек/лиги), `NOTIFY` (уведомления игроку), `TELEGRAPH` (мобы иногда замахиваются: тик-предупреждение, затем удар ×2.2 — есть ход, чтобы прервать контролем, закрыться щитом/уклонением, полечиться, добить или отойти) и `RULES_V2` (гибридное ядро правил: типы урона, резисты, спасброски, мультиатака). Каждый можно отключить переменной окружения или в `.env`, например `NPC_AI=0`. `RULES_V2` включён по умолчанию с спринта 7: мультиатака после балансировки (`multiattack_scale`, спринт 6) укладывается в целевой коридор ±25% ΔDPS для всех 6 классов (Monte-Carlo N=350×30 раундов, см. `sims/sim_rules2.py`); последний блокер — профиль мобов `spirit`, резистивший сразу все физические типы урона — снят решением лида: дробящее (bash — освящённая булава/посох) сокрушает бесплотную форму и проходит, режущее/колющее (pierce/slash) по-прежнему резистится. Против undead/demon/default все 6 классов в коридоре ±25%; против spirit классы с дробящим оружием (priest/paladin) и воин тоже в коридоре, mage/rogue/necromancer (кинжал/лук) осознанно проседают — контрплей у всех классов даёт 100% боевых скиллов, уже нефизических по типу урона. Полный список и обоснование дефолтов — в `.env.example`.

## Как расширять мир

Добавить комнату — допиши блок в `world.yaml` и пропиши выход из существующей. Новый моб — `mobs.yaml` + добавь его id в `spawns` комнаты. Новый предмет — `items.yaml`. При запуске `engine/content.py` валидирует ссылочную целостность (несуществующие выходы/мобы/лут — ошибка с указанием места):
```bash
python -m engine.content   # проверка контента
```

## Заметки по продакшену

- Состояние мобов (HP, респавн, агро) живёт в памяти процесса — при рестарте бот возрождает мир из YAML. Персонажи персистятся в Postgres.
- Игровой цикл тикает раз в секунду одной фоновой задачей; масштабируется до сотен игроков на одном процессе. Для тысяч — шардировать по зонам.
- Сохранение идёт после каждого значимого действия; для высокой нагрузки стоит добавить дебаунс/батчинг записи.
```
